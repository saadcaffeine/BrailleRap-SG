# BrailleRAP Singapore website

One-page site for the BrailleRAP and BrailleRAP XL in Singapore, served by GitHub Pages from this `gh-pages` branch.

Live site: https://saadcaffeine.github.io/BrailleRap-SG/

`index.html` is self-contained (inline CSS and JS, Atkinson Hyperlegible Next from Google Fonts). The Braille on the page is drawn as real UEB grade 1 dot geometry at true scale (2.5 mm dots, 6 mm cells, 10 mm lines on an A3 sheet).
